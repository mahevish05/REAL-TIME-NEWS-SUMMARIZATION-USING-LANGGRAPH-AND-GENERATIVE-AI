# Real-Time News Summarization Using LangGraph and Generative AI

## Overview
This project fetches real-time news articles and generates AI-powered summaries using LangGraph and Generative AI.

## Features
- Fetches latest news
- Summarizes articles using AI
- User-friendly Streamlit interface

## Technologies Used
- Python
- Streamlit
- LangGraph
- Generative AI
- Requests
